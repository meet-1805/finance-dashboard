# Finance Dashboard

A full-stack personal finance management application built using Angular, Node.js, Express.js, and MongoDB.

## Features

- User Authentication (JWT)
- Income Management
- Expense Management
- Dashboard Overview
- Budget Tracking
- Protected Routes
- MongoDB Database

## Tech Stack

Frontend:
- Angular
- TypeScript
- HTML
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT
